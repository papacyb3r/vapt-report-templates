# VAPT Report Templates

Sanitized, reusable templates for vulnerability assessment and penetration testing (VAPT) engagements. Built from experience delivering 30+ engagements; contains **no client data**.

## Contents

| File | Purpose |
|---|---|
| [rules-of-engagement.md](rules-of-engagement.md) | Scope, authorisation and testing-window checklist to agree before testing starts |
| [report-structure.md](report-structure.md) | Recommended structure for an executive summary plus technical report |
| [finding-template.md](finding-template.md) | One-page template for documenting each finding |
| [severity-rating.md](severity-rating.md) | Consistent severity rating approach using CVSS |

## Principles

- **Two audiences:** executives need business risk and priorities; engineers need reproducible steps and fixes.
- **Evidence over assertion:** every finding carries proof (request/response, screenshot, command output).
- **Actionable remediation:** each finding names a specific fix and an owner-friendly priority.
- **Consistent rating:** the same method on every finding so reports are comparable over time.

## Usage

Copy the files into your engagement folder and replace the <placeholders>. Keep client names, hostnames and data out of anything you publish.
